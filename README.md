# Tim's Daily Dashboard

Personal dashboard updated by daily scheduled Claude tasks.

**Live URL:** https://[YOUR-GITHUB-USERNAME].github.io/tim-dashboard

## Tabs
- ☀️ **Morning Brief** — Today's calendar, flagged emails, action items
- 💼 **Business Listings** — BizBuySell/BizQuest deals matching Tim's criteria
- ✈️ **Flight Watch** — STL↔DEN sub-$200 day-trip deal alerts
- ⛵ **Catamaran Watch** — Liveaboard cats under $60K in the US

## Data files (updated by scheduled tasks)
- `data/morning.json` — Morning brief data
- `data/business.json` — Business for sale listings
- `data/flights.json` — Flight deals
- `data/catamaran.json` — Catamaran listings
